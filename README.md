# 🧮 Calculadora de Matrizes

Uma aplicação web interativa desenvolvida com **HTML**, **CSS** e **JavaScript** puro (Vanilla JS) para criação, manipulação e cálculo de operações matriciais.

---

## 🎯 Sobre o Projeto

O projeto nasceu com dois objetivos principais:
1. **Prática e aprofundamento em JavaScript:** manipulação dinâmica do DOM, estruturas de dados multidimensionais e lógica de programação.
2. **Fixação prática de Álgebra Linear:** aplicar diretamente na programação os conceitos aprendidos na disciplina da faculdade, facilitando o entendimento de propriedades e operações matriciais.

A ideia inicial é começar com o essencial (criação dinâmica de matrizes, soma, subtração e multiplicação) e, progressivamente, expandir para operações avançadas como cálculo de determinantes, matriz transposta, inversa e resolução de sistemas lineares.

---

## ✨ Funcionalidades

### Atuais
- [x] Criação dinâmica de matrizes informando nome, quantidade de linhas ($m$) e colunas ($n$).
- [x] Renderização interativa de células de entrada para preenchimento dos valores da matriz.

### Próximos Passos (Roadmap)
- [ ] **Operações Básicas:**
  - [ ] Soma de matrizes ($A + B$)
  - [ ] Subtração de matrizes ($A - B$)
  - [ ] Multiplicação por escalar ($k \cdot A$)
  - [ ] Multiplicação de matrizes ($A \times B$)
- [ ] **Operações Avançadas:**
  - [ ] Matriz transposta ($A^T$)
  - [ ] Determinante ($1 \times 1$, $2 \times 2$, $3 \times 3$ via Sarrus e ordens maiores via Teorema de Laplace)
  - [ ] Matriz inversa ($A^{-1}$)
- [ ] **Interface & Usabilidade:**
  - [ ] Validação de dimensões para operações matemáticas válidas
  - [ ] Opção de limpar e remover matrizes criadas
  - [ ] Visualização passo a passo da resolução dos cálculos

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização e layout dos elementos e grades matriciais.
- **JavaScript (ES6+):** Lógica de geração dinâmica e operações matemáticas.

## 🚀 Como Executar o Projeto

Não é necessário instalar dependências. Basta ter um navegador web.

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/LeonardoFortunato13/calculadora-de-matrizes.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd calculadora-de-matrizes
   ```

3. **Abra o arquivo `index.html`:**
   - Dê um duplo clique no arquivo [index.html](file:///c:/Users/Leonardo/Repositorio/calculo-matriz/index.html) ou abra utilizando extensões como o *Live Server* do VS Code.
